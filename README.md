# CSVTOOLS
Fortran Utility for handling CSV files

## Description
Compact Fortran library to handle CSV data and files.

## Requirements
* Fortran compiler (e.g. gfortran)
* cmake

## Build and Test

### Build
Run the following commands:
```
mkdir build
cd build
cmake ..
make 
```

### Test
Run ctest:
```
ctest
```

## Linking the library
Link the library to an application with `-lcsvtools`.
